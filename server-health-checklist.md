
# Dell iDRAC Server Health Checklist

## Overview

This checklist covers basic hardware health checks for Dell PowerEdge servers using iDRAC.

## 1. System Health

- Check overall server health status.
- Review active hardware alerts.
- Check the System Event Log.
- Look for any critical warnings.

## 2. CPU and Memory

- Check CPU health status.
- Review memory health.
- Look for hardware errors or warnings.

## 3. Storage and RAID

- Check physical disk health.
- Review virtual disk and RAID status.
- Identify failed or degraded disks.
- Check for storage controller alerts.

## 4. Power and Cooling

- Check power supply status.
- Review fan health.
- Check temperature sensors.
- Look for cooling or power warnings.

## 5. Remote Management

- Verify iDRAC accessibility.
- Check remote console availability if licensed.
- Review server power status.
- Confirm management access permissions.

## Basic Troubleshooting

| Issue | Initial Check |
|---|---|
| Disk failure | Physical disk and RAID health |
| Server overheating | Temperature and fan status |
| Power warning | Power supplies and event logs |
| Server not booting | Hardware alerts and boot logs |
| iDRAC inaccessible | Network connectivity and access permissions |

## Important Note

Do not restart a production server, change RAID settings or perform firmware updates without following the approved change procedure.

This checklist contains general technical guidance only.
