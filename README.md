
# Dell iDRAC Server Management

## Overview

This repository contains notes on Dell iDRAC and physical server management.

iDRAC is used to manage and monitor Dell PowerEdge servers remotely, including when the operating system is not running.

## Server Health Monitoring

Important areas to check include:

- Server power status
- CPU and memory health
- Temperature and cooling fans
- Power supplies
- Physical disks and RAID status
- Hardware warnings and alerts

## Remote Management

Depending on the iDRAC version and license, administrators can:

- View server hardware information
- Access the remote console
- Check system event logs
- Perform remote power operations
- Mount installation media remotely

## Basic Troubleshooting

| Issue | What to Check |
|---|---|
| Server not responding | Power status and hardware alerts |
| Disk warning | Physical disk and RAID status |
| High temperature | Fans, sensors and cooling |
| Server boot issue | System logs and boot settings |
| Remote access issue | iDRAC connectivity and permissions |
